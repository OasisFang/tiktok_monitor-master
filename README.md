# TikTok 直播监控系统

一个实时监控 TikTok 直播数据的系统，支持多账号并发监控、数据分析和历史记录。

## 🎯 主要功能

- **实时监控**：监控多个 TikTok 直播间的实时数据
- **数据记录**：自动记录观众数、点赞、评论、礼物等互动数据
- **历史分析**：提供详细的历史数据分析和趋势图表
- **多账号支持**：同时监控多个账号，智能调节请求频率
- **防检测模式**：可选的防检测功能，减少被限制的风险
- **数据导出**：支持JSON和CSV格式的数据导出

## 📁 新数据结构 (v2.0)

系统已升级到新的数据存储结构，更适合数据分析且避免文件过大：

### 文件结构
```
history/
├── index.json                           # 总索引文件
├── user1/                              # 每个账号独立文件夹
│   ├── session_20231210_143052.json    # 每场直播独立文件
│   ├── session_20231210_201530.json
│   └── ...
├── user2/
│   └── session_20231211_090000.json
└── backup_old_format/                  # 旧格式数据备份
    ├── daily/
    └── sessions/
```

### 会话文件结构
每个会话文件包含：
- **基本信息**：开始/结束时间、时长、房间ID、标题
- **总体统计**：观众数、点赞数、评论数、礼物数等（仅数量）
- **每分钟数据**：压缩格式的时间序列数据
- **配置信息**：防检测设置、自定义间隔等

### 数据优化特性
- ✅ **压缩存储**：使用简化键名减小文件大小
- ✅ **分离存储**：评论和礼物详细内容不保存到历史文件
- ✅ **实时显示**：直播间详情仍显示最近10条评论/礼物
- ✅ **独立文件**：每场直播独立文件，便于数据分析
- ✅ **自动迁移**：首次启动时自动从旧格式迁移数据

## ⚙️ 配置选项

### 监控设置
- **防检测模式**：启用后使用更保守的请求策略
- **自定义间隔**：设置监控检查间隔（1-500秒）
- **会话ID**：可选，用于绕过年龄限制

### 并发控制
- **最大并发连接**：默认5个
- **智能间隔调整**：根据监控账号数量自动调整
- **错开启动**：避免同时请求API造成限制

## 📋 API 接口

### 监控管理
- `POST /start_monitor` - 开始监控
- `POST /stop_monitor` - 停止监控
- `GET /list_monitors` - 获取监控列表
- `GET /get_stream_data` - 获取流数据

### 历史数据
- `GET /api/history/user/<unique_id>` - 获取用户历史
- `GET /api/history/summary` - 获取每日汇总
- `GET /api/history/users` - 获取用户列表
- `GET /api/history/analytics/<unique_id>` - 获取分析数据
- `GET /api/history/session/<unique_id>/<session_id>` - 获取会话详情

### 数据管理
- `GET /api/history/export` - 导出数据
- `POST /api/history/clear` - 清除数据
- `GET /api/history/stats` - 数据统计

## 🔍 使用说明

### 添加监控
1. 输入TikTok用户名（不含@符号）
2. 可选设置SessionID和防检测模式
3. 点击"开始监控"

### 查看数据
1. 在主页面查看实时数据
2. 点击直播卡片查看详细信息
3. 使用"历史数据分析"查看趋势

### 数据导出
1. 访问历史数据页面
2. 选择用户和格式
3. 点击导出按钮下载文件

## 🚨 注意事项

1. **合规使用**：仅用于合法的数据分析目的
2. **频率控制**：避免过于频繁的请求
3. **隐私保护**：不记录用户个人信息
4. **资源占用**：监控多个账号时注意系统资源
